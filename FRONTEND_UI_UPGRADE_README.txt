GlobeTrotter Frontend UI Upgrade

This package contains FRONTEND-ONLY changes.

Copy/merge these folders into your existing GlobeTrotter project:
- templates/
- static/

Do NOT replace your backend apps or backend developer files with this package.

Highlights:
- Odoo-inspired editorial visual system
- Real SVG paint-stroke accents (not pill-shaped boxes)
- Handwritten Caveat accent typography
- Orange / teal / blue / purple brush motifs
- Hand-drawn arrows and CTA callouts
- Structured editorial sections and dividers
- Crisp Odoo-style application shell polish
- No gradients
- No shadows
- No hover motion
- Preserves Django template routing and existing backend integration points
