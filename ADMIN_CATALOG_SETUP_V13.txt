Dynamic City + Activity catalog — Admin-ready V13

The frontend is database-driven. To add a new place or activity from Django Admin:

  1. Open /admin/
  2. Add a City under Destinations > Cities.
     Required:
       - Name
       - Country
       - Region (optional)
       - Description
       - Cost index 0-100
       - Popularity 0-100
       - Image upload OR External image URL

  3. Add an Activity under Activities > Activities.
     Required:
       - City
       - Name
       - Description
       - Activity type
       - Duration in minutes
       - Estimated cost
       - Image upload OR External image URL

  4. Refresh /discover/cities/ or /discover/activities/.
     The new records are loaded dynamically from the database.

Recommended initial catalog:
  python manage.py migrate
  python manage.py seed_travel_catalog

Important:
  - Local uploaded images take priority over external_image_url.
  - No city/activity is hardcoded into the HTML.
  - The itinerary builder uses the same City and Activity records.
  - Adding an admin record immediately makes it available for itinerary planning.
