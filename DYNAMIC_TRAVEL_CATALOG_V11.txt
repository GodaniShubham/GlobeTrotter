Dynamic Travel Catalog V11

Problem:
  The itinerary screens were working against the real City and Activity tables, but
  an empty MySQL database meant the Discover Cities and Discover Activities screens
  had nothing to display.

Solution:
  Added an idempotent Django management command:
      python manage.py seed_travel_catalog

  It loads a realistic starter catalog of 18 cities and 100+ city activities
  into the existing destinations.City and activities.Activity models.

  You can run it against SQLite locally or MySQL in the backend developer's environment.

Custom dynamic data:
  Use Django Admin to add or edit City and Activity rows. No frontend code change is needed.
  The Discover pages query the DB each request, so newly added cities/activities appear automatically.

Recommended setup:
  1. python manage.py migrate
  2. python manage.py seed_travel_catalog
  3. python manage.py runserver

Rebuild the seeded catalog:
  python manage.py seed_travel_catalog --reset

This uses the project's existing database models and does not introduce a second catalog system.
