FORGOT PASSWORD ROUTE (BACKEND-SAFE PATCH)
==========================================

The 404 is not a frontend-template problem anymore. The frontend link points to:

    /forgot-password/

Your current config.urls.py does not have this URL yet.

1) In config/views.py, add:

    def forgot_password(request):
        return render(request, "pages/forgot_password.html")

2) In config/urls.py, add this alongside login/signup:

    path("forgot-password/", views.forgot_password, name="forgot_password"),

Do NOT replace your existing views.py or urls.py wholesale.
Add only the function + URL above so the backend developer's existing work stays intact.

After saving:

    python manage.py runserver

Then test:

    http://127.0.0.1:8000/forgot-password/

No database/authentication logic is changed by this patch.
